Lesson 5 / 行程规划（基础项 A）

把「行程规划」工人做实：两阶段管线

这是你作业的评分核心——价值产出者。做完这课，你的系统第一次给出真正有用的答案。

和你的使命的关系

第一课我们纠正过一个误区：行程规划 Agent 是核心价值产出者，不能用程序替代。第四课的桩节点只是占位；这一课把它做实——用户说一句差旅需求，系统真的排出一份行程。你离「能演示 3 类案例」又近了一大步。

架构：worker 内部也是一条流水线

用户原话
  │  ① 要素提取（LLM，结构化输出）
  ▼
TripRequest { 出发地 / 目的地 / 日期 / 天数 / 住宿偏好 / 预算 }
  │  ② 行程生成（LLM，结构化输出）
  ▼
ItineraryPlan { 逐日安排（交通/住宿/活动/备注）+ 总结 }
  │  格式化
  ▼
用户可读的行程文本

注意：作业把「要素提取」列为独立 Agent。我们先做在 worker 内部——它和行程生成是一对强耦合的步骤，拆出去只会徒增上下文搬运（第一课教训）。等以后要素提取真的要被别的 Agent 复用，再拆成独立节点/Agent 也不迟（这就是「深模块」：先做内聚，再考虑拆）。

核心代码（已实测，两段行程都合理）

① 两阶段各自的 schema 和提示词

class TripRequest(BaseModel):
    from_city: str; to_city: str
    start_date: str          # 没给日期 → 模型填"待定"
    duration_days: int
    hotel_pref: str          # 没有 → "无"
    budget_pref: str         # 没有 → "中等"

class ItineraryPlan(BaseModel):
    days: list[DayPlan]      # 每项：date/transport/hotel/activities/notes
    summary: str             # 给用户看的中文总结

两段都用 method="json_mode" + 键名写死 + 花括号转义——第三课攒下的可用配置直接复用。这就是做课程的好处：工具沉淀成模板，后面每个 Agent 都用同一套。

② 一个容易踩的坑：prompt | model 组合

# ❌ 分开定义后直接 invoke dict——报错 Invalid input type
extract_model = llm.with_structured_output(TripRequest, method="json_mode")
extract_model.invoke({"input": ...})   # 裸模型不认 dict！

# ✅ 必须组合成链
extract_model = extract_prompt | llm.with_structured_output(TripRequest, method="json_mode")
extract_model.invoke({"input": ...})   # prompt 链才认 {"input": ...}

这个 bug 我写示例代码时当场踩过。记住：with_structured_output 之前要先接一个 prompt（或用别的方式把消息准备好）。

③ worker 节点：两次 LLM 调用串起来

def itinerary(state):
    req = extract_model.invoke({"input": state["user_input"]})   # ① 提取
    plan = plan_model.invoke({                                    # ② 生成
        "trip_json": req.model_dump_json(),   # 提取结果作为生成阶段上下文
        "user_input": state["user_input"],
    })
    return {"answer": format_plan(plan)}      # 返回用户可读文本

注意返回值：worker 写给用户的是格式化文本（format_plan），不是 JSON。JSON 是内部管道语言，用户看到的是人话。

诚实的质量声明

模型排出的班次号（如「G31 次 08:30」）是参考方案，不是真实可预订班次——它会根据常识编造。真实产品里，行程生成后要接校验层：查差旅政策（RAG）、查实时班次（ToolNode/联网）。这正是你作业「加分项」的落点，也是后面课程的内容。现在先别让它骗了你自己：演示时可以说「这是参考行程」。

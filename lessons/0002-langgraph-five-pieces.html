Lesson 2 / LangGraph 实操

LangGraph 五件套：把「一个 Agent」真正搭起来

上节课你学会了判断拆不拆；这节课学把它变成代码的原子构件。

和你的使命的关系

你要独立设计并实现差旅多 Agent 系统。LangGraph 里的一切都建立在五个构件上：状态、节点、边、工具、运行。把它们吃透，你作业里「拆出来的每个角色」就只是图里的一个节点，「调度」就只是一条条件边——这是你从设计通往代码的桥。

心智模型：一张图

LangGraph 把 Agent 建模成图，官方原话是：「节点干活，边决定下一步去哪」（Nodes and Edges are nothing more than functions—they can contain an LLM or just good ol' code）。来源：LangGraph Graph API 官方文档。

  • State（状态） —— 一张共享的数据结构（TypedDict），所有节点都读它、更新它
  • Node（节点） —— 一个普通 Python 函数：收当前状态，返回部分更新
  • Edge（边） —— 决定下一个执行哪个节点：固定跳转或条件路由
  • ToolNode（工具） —— 执行模型发起的工具调用
  • 编译与运行 —— compile() 成应用，invoke() 跑起来

五件套逐个拆开

① State：先定义图里传什么

State 是一个 TypedDict。每个 key 有自己独立的「归约器」（reducer），决定多个节点都改这个 key 时怎么合并：

  • 默认 reducer = 覆盖：后写的值替换先写的值（官方称 default reducer 丢弃旧值保留新值）
  • 消息列表用 add_messages：自动追加而不是覆盖
  • 预制 MessagesState：只有一个 messages key 的现成 State，可继承加字段

② Node：一个节点就是一个函数

节点接收当前 state，返回部分更新——不用返回整个 State，只返回你要改的 key 就行。节点里可以调 LLM，也可以只写纯代码。没给节点起名时，默认用函数名当节点名。

③ Edge：固定跳与条件路由

add_edge(A, B) 是固定跳转。关键的是 add_conditional_edges(节点, 路由函数)：路由函数接收 state，返回下一个节点的名字（也可以配一个「返回值→节点名」的映射字典）。入口是虚拟节点 START，出口是 END。

④ 工具：模型要调工具，谁来执行

模型说「我要调 weather()」时，ToolNode 负责真的去执行，并把结果以 ToolMessage 回填给模型。它自动处理并行执行和错误。标准 ReAct 循环（思考→调工具→看结果→再思考）官方推荐直接用 create_agent 一步到位；需要精细控制（比如我们作业的多 Agent 调度）才手写图。

⑤ 运行：compile 与 invoke

app = graph.compile() 做结构检查（比如有没有孤儿节点），然后 app.invoke(初始状态) 跑完整张图，返回最终完整状态。默认递归上限 1000 步。

一个实测过的完整例子

下面这段代码我在你的环境（langgraph 1.2.10）里跑过，输出 北京→你好。先把它读熟，它就是你的模板：

from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END, add_messages
from langchain_core.messages import AnyMessage

class State(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]  # 消息自动追加
    city: str                                            # 默认：覆盖

def identify(state):      # 节点：收 state，返回部分更新
    return {"city": "北京"}

def greet(state):
    return {"city": state["city"] + "→你好"}

graph = StateGraph(State)
graph.add_node(identify)
graph.add_node(greet)
graph.add_edge(START, "identify")
graph.add_edge("identify", "greet")
graph.add_edge("greet", END)
app = graph.compile()
result = app.invoke({"messages": [], "city": ""})
print(result["city"])

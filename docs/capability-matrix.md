# 能力矩阵

| 类型 | 当前能力 | 证据或标识 | 明确边界 |
|---|---|---|---|
| 实时事实 | 查询天气 | 外部工具结果 | 失败显式呈现，不编造预报 |
| 政策事实 | 从 8 份政策语料检索并回答 | 回答携带 RAG 来源；状态为 `grounded` | `not_found` 正常拒答；`unavailable/stale/ambiguous` 明确降级，不推断政策数字 |
| 规划估算 | 按经济/中等/舒适档估算住宿与餐饮 | 输出标注“非报价、非公司政策” | 不估算交通金额；不把估算当报销标准或供应商报价 |
| 模型建议 | 生成逐日行程、活动顺序和说明 | 结构化行程经过日期、天数和政策证据校验 | 建议不是预订、审批、报销或安全保证 |
| 可执行操作 | 保存用户偏好与行程历史 | JWT 用户隔离；Postgres 持久化 | 不下单、不支付、不提交审批、不修改第三方系统 |

天气失败必须显式显示，不能用猜测补齐。票务（车次、时刻、余票、票价、购票）不在晓问能力范围内，
由商旅平台承担；行程只建议交通方式，不生成购票链接。当前运行形态支持单应用实例；migration、
连接池和多实例协调属于后续演进。

# 能力矩阵

| 类型 | 当前能力 | 证据或标识 | 明确边界 |
|---|---|---|---|
| 实时事实 | 查询天气；生成 12306 官方查询链接 | 外部工具结果；官方站点代码与日期校验 | 不提供车次、时刻、余票、票价、订单或购买结果 |
| 政策事实 | 从 8 份政策语料检索并回答 | 回答携带 RAG 来源；状态为 `grounded` | `not_found` 正常拒答；`unavailable/stale/ambiguous` 明确降级，不推断政策数字 |
| 规划估算 | 按经济/中等/舒适档估算住宿与餐饮 | 输出标注“非报价、非公司政策” | 不估算交通金额；不把估算当报销标准或供应商报价 |
| 模型建议 | 生成逐日行程、活动顺序和说明 | 结构化行程经过日期、天数和政策证据校验 | 建议不是预订、审批、报销或安全保证 |
| 可执行操作 | 保存用户偏好与行程历史；生成外部查询链接 | JWT 用户隔离；Postgres 持久化 | 不代购票、不下单、不支付、不提交审批、不修改第三方系统 |

天气失败必须显式显示，不能用猜测补齐。车站无法从官方数据唯一解析时要求用户确认，不猜测
电报码。当前运行形态支持单应用实例；migration、连接池和多实例协调属于后续演进。

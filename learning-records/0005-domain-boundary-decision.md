# 产品边界决策：意图规则 = 产品边界（含回归测试）

第四课任务中，用户加入测试句「这个暑假去哪里玩」，模型归为「行程规划」。指出：企业差旅助手不应接个人休闲游规划——意图规则必须编码产品边界。

## 用户做对的
- 加了两句有代表性的测试：模糊句「帮我看看出差的事」+ 边界句「这个暑假去哪里玩」
- 模糊句被正确归为行程规划（无行程细节，纯语义判断——说明 LLM 意图识别达到设计目的）
- 自己动手把测试句加进了 homework/0004_scheduler.py 的 tests 列表（回归测试意识，虽然当时规则还没改）

## 本次设计决策
- **决策**：个人休闲/旅游规划归「其他」，reason 说明「非企业差旅服务范围」
- **理由**：产品定位清晰 + 避免行程规划 Agent 被非差旅需求污染（对应第一课上下文污染概念）
- **实现**：系统提示词加边界规则「本助手只服务企业差旅；个人休闲/旅游规划一律归其他」
- **验证**：8/8 全部正确；边界句 reason 明确写出「不属于企业差旅服务范围」
- 已提示：如果产品要接个人游是另一个产品决策，但要显式做出来，而不是让模型随手决定

## 教学要点
- 意图分类的规则集本质是产品边界说明书，随产品演进要维护
- 用户自己的测试句保留为回归测试——以后改规则立刻能看出边界是否守住

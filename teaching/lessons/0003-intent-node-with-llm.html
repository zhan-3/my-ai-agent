① 你的「中转站」= OpenAI 兼容接口

DeepSeek 官方接口是 OpenAI 兼容格式（同一套协议）。中转站本质就是「转发到各家模型、仍按 OpenAI 协议」的服务，所以接入方式完全一样——只是 base_url 换成中转站地址、api_key 换成中转站给的 key。

LangChain 里用 ChatOpenAI 连这类接口（本课开始前已安装 langchain-openai）：

from langchain_openai import ChatOpenAI
import os
from dotenv import load_dotenv

load_dotenv()  # 从项目根目录的 .env 加载三个变量（也可保留 shell export）

llm = ChatOpenAI(
    model=os.environ["DEEPSEEK_MODEL"],      # 中转站给的模型名
    base_url=os.environ["DEEPSEEK_BASE_URL"], # 中转站地址，通常以 /v1 结尾
    api_key=os.environ["DEEPSEEK_API_KEY"],  # 中转站 key
    temperature=0,                            # 分类任务：0 = 最稳定
)

环境变量放哪里（两种选一，推荐 .env）：

# 方式一（推荐）：编辑项目根目录的 .env 文件（已建好骨架，填真实值即可）
DEEPSEEK_API_KEY=sk-你的中转站key
DEEPSEEK_BASE_URL=https://你的中转站地址/v1
DEEPSEEK_MODEL=deepseek-chat

# 方式二：终端 export（临时，关终端就没了）
export DEEPSEEK_API_KEY="sk-..."

安全习惯

key 永远不进代码、不进 git。用环境变量（export）或 .env 文件。这也是作业「工程质量」加分项的一部分。

② 让模型输出结构化结果：with_structured_output

意图识别要的是「类型 + 理由」，不是一段散文。用 with_structured_output 声明一个 schema，模型会按这个结构返回：

from pydantic import BaseModel, Field
from typing import Literal

class Intent(BaseModel):
    """用户这句话属于哪类任务"""
    intent: Literal["行程规划", "偏好记录", "历史查询", "知识问答", "联网查询", "其他"]
    reason: str = Field(description="一句话理由")

intent_model = llm.with_structured_output(Intent)

调用 intent_model.invoke("我下周去杭州出差") 会直接返回一个 Intent 实例（result.intent、result.reason），模型负责把输出塞进 schema。这是作业「不建议关键词 if-else 硬匹配」的正解。

③ 节点 = 一次 LLM 调用

把上一步包成一个节点函数，放进图里——这是你的第一个「有大脑的节点」：

from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END, add_messages
from langchain_core.messages import AnyMessage

class State(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]  # 官方惯例名：messages
    user_input: str
    intent: str
    reason: str

def classify_intent(state):
    result = intent_model.invoke(state["user_input"])   # 调 LLM
    return {"intent": result.intent, "reason": result.reason}  # 写回 state

graph = StateGraph(State)
graph.add_node(classify_intent)
graph.add_edge(START, "classify_intent")
graph.add_edge("classify_intent", END)
app = graph.compile()

for t in ["我下周从北京去杭州出差三天，喜欢住连锁酒店",
          "帮我查一下报销标准是多少",
          "我喜欢住汉庭"]:
    r = app.invoke({"messages": [], "user_input": t})
    print(f"{t!r} → {r['intent']}（{r['reason']}）")

注意：state 里消息字段这次用了 messages（官方惯例，也是上节课提醒你的）。

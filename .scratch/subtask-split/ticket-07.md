# 07 — 多意图拆分兜底（顺便/还有 子句被吞）

**What to build:** classify 一次调用干两件事（主导意图 + 拆分 subtasks），主导意图清晰时 LLM
常把「顺便/还有X」整句吞掉、subtasks 返回空（黄金集 3 条失败全为此模式）。
修法：classify 后 subtasks 为空且输入含强拆分标记 → 确定性切句 → 尾部子句再分类补进 subtasks。

**规则（防误拆）**：拆分标记 `顺便/顺带/顺道/另外/还有` 必须**前接子句分隔符**（，。；！？）
才算拆分点——「我还有事」的「还有」前面没有逗号 → 不拆。
子句分类后与主导意图相同或归「其他」→ 跳过（防重复/垃圾子任务）。

**Blocked by:** None

**Status:** ready-for-agent

- [ ] `intent.py`：`_split_subtasks`（纯函数）+ classify 兜底追加
- [ ] 单测（桩 LLM）：切句（单/多标记/无标记/「我还有事」不拆）、补全、同意图跳过、其他跳过
- [ ] 黄金集 3 条失败用例转稳 + 门禁全绿

## Answer

已实现并验证：黄金集 79/79（100%，历史首次全绿）。
- 兜底：subtasks 空 + 强拆分标记（顺便/顺带/顺道/另外/还有，须前接子句分隔符防误拆）→ 切句再分类补进
- 归一化：subtasks 非空但缺主导 → 前置主导（text=完整输入），对齐黄金 [主导, 次要] 契约与 dispatch 兜底语义
- 10 单测（桩 LLM）+ 门禁全绿
